# 🏥 Hospital Patient Data Analysis

📌 Overview

This project analyzes hospital patient data using **SQL** and **Microsoft Excel**. It helps extract useful information such as patient statistics, department-wise reports, treatment costs, heart rate analysis, and hospital stay details. :contentReference[oaicite:0]{index=0}

🛠️ Tools Used

- SQL (MySQL)
- Microsoft Excel

 📊 Project Tasks

- Total number of patients
- Average patient age
- Department-wise patient count
- Treatment cost analysis
- Heart rate analysis
- Blood pressure analysis
- Oxygen saturation analysis
- Hospital stay analysis
- Equipment usage summary
- Admission date analysis
